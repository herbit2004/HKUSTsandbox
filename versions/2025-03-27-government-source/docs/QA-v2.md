## 交付范围

- 原292片摄影网格继续作为基础；328份去重原纹理最高2048像素，按视距读取和释放。流畅、自动、精细三档可切换。
- 55片1m地形按需读取，自动最多4片、精细最多8片；已载入处遮去5m粗网格，回退恢复粗网格。源资料仍是2019–2020年DTM。
- 4个完整高LOD区域按需整体替换7片基础网格，同一时间一个区域；主楼北部另有fine层级。资源完整后才替换，取消或失败保留基础网格。
- 18栋建筑和4个具名空间采用真实公开多边形判断和线框提示。新增5处具体位置，使索引中独立定位34→39、父楼聚焦14→10；26条仍无独立定位。原地图配准点的不确定性保留。
- 室内整栋跨层房号搜索、选择高亮、关闭返回状态、照片叠加和本层附近全景。保留19栋78层及63层CAD，4,301个可互动多边形部分不等于4,301个独立房间。
- 全景按建筑/楼层打开，提供官方点边位置图、上一现场、键盘环顾/缩放/数字相邻点。图像按需请求并取消过期请求，仅当前影像驻留。
- Shaw、CYT两栋已核实名政府逐栋模型可独立查看外观并进入对应室内。两栋共8,687三角形、4,723,596源资产字节。其余51栋仅有研究索引和原始资料，未接入网站、未补造名称。

## 性能与地形精度证据

同一相机 `[565.05,251.72,-1480.08]`，目标 `[425.05,121.72,-1625.08]`，单机可见页面采样。渲染器主动限制约30帧，以下不是跨设备性能保证；CPU提交时间不是GPU耗时。原始记录：[v2-browser-performance.json](v2-browser-performance.json)。

|指标|流畅基线|精细|返回流畅|
|---|---:|---:|---:|
|实际绘制三角形|630,772|1,948,460|630,772|
|绘制调用|189|246|189|
|渲染器纹理数|489|565|489|
|渲染器几何数|1,098|1,159|1,098|
|近处原纹理 / 细地形|0 / 0|24 / 8|0 / 0|
|采样帧率|25.9|29.8|30.0|
|CPU提交中位数ms|3.7|6.3|1.3|

资源回退后纹理数、几何数和绘制量均回到同一基线。精细状态本次原纹理估算96MiB，高LOD网格纹理另估算224MiB；这两项不是浏览器或GPU总内存。已加入并发/容量上限与过期请求取消，未执行手机触控、长时间压力或跨设备测试。

1m地形2,737,518个导出顶点逐一比对源Float32高度差为0；55片的5,425,430个三角形均有源有效网格支持。20,845对共享接缝顶点的位置和法线差为0，旧5mGLB哈希保持不变。见 `public/terrain/detail/independent-qa.json`。

247,614个相同源参考点的三角网格插值RMSE：5m为0.300094m，1m为0.069853m；P95绝对误差0.550423→0.100194m。**这是同一份旧DTM的显示重采样误差，不是现实测绘精度。** 1m局部最大误差仍为7.685m，不能以均值掩盖陡变位置；缺值未补造。详见 `public/terrain/detail/sampling-error.json`。

## 构建与资源检查

- `npm run check` / TypeScript通过。
- `npm run build`通过，输出 `dist/client` 静态资源。Three.js包体大于500kB的提示仍存在，非构建失败。
- 最终构建预渲染首次受沙盒本机监听限制（EPERM），允许监听后原命令成功退出0。最终public/dist的coverage、catalog、地形与逐栋manifest字节一致；重新打开原入口全部基础模型载入，性能默认折叠，浏览器error为空。
- `python3 scripts/validate-data.py` 实际完整执行v1和v2，退出0、`errors=[]`。验证292片原网格、78层、63层CAD、41照片、14缓存全景；新增55片地形、4patch/162个层级GLB引用、328份原纹理哈希、2栋逐栋模型的直接依赖及4,301条搜索索引。结果：[data-validation.json](data-validation.json)。

来源修订日期不等于拍摄日期；室内边界0–3m为读图示意，独立外观未推造室内结构。联网目录2,044张并未逐张人工核验；位置图边不保证现场通行或最短路。轮廓来自公开平面，线框的显示高度不是测量屋顶高度，复杂带洞区域不填造成实体体积。
