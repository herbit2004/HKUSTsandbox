# 香港科技大学清水湾 · 三维校园地图

这是用于**交互浏览与校园认路**的本地校园模型，范围为香港清水湾校区，非广州校区。资料查证日为 **2026-09-05**。地形、外观、楼内平面、照片和使用状态分别保留各自来源与日期。

## 打开

本机入口：[http://127.0.0.1:4317/](http://127.0.0.1:4317/)。

以后可双击同目录 `启动校园地图.command`，保持终端窗口开启，再打开上述地址。或在此目录执行：

```sh
python3 scripts/serve.py --port 4317
```

只监听本机。模型、地图、41张照片、14处缓存全景均可断网使用；“更多官方全景（联网加载）”与官方来源链接需要网络。不能直接双击HTML运行，因为GLB、CAD和JSON需要本地HTTP读取。已有静态构建在 `dist/client`，正常使用不需要重新安装或构建。

## 能做什么

- 拖动旋转、右键平移、滚轮缩放；查看全校园、北向俯视和海岸视角。
- 搜索教学楼、宿舍、研究楼、文化运动设施等75条索引。39条有独立证据定位，10条命名空间明确聚焦所属建筑；其余保留官方图面位置线索与原图入口。**75条索引不等于75栋独立建筑**，其中包含翼、命名空间及地标。
- 显隐真实地表网格、LiDAR地形、地点标签、官方无障碍点位、2026更新包络。分类筛选控制地点标签；政府摄影网格融合了建筑与地表，未全部逐栋分割。
- 选择“流畅 / 自动 / 精细”清晰度：流畅保留512像素纹理和5m地形；自动与精细按距离读取原纹理、1m地形和有真实来源的高LOD局部分块。性能详情显示当前绘制、纹理估算及加载状态；可切回流畅。
- 有公开轮廓的建筑可按轮廓选中并高亮；新增缩放按钮、上一视角和局部细节入口。逸夫演艺中心、郑裕彤楼可从建筑卡单独旋转查看原纹理外观，再进入对应楼层。
- 高程剖切显示网格外壳截面，不代表室内结构。
- 点击“室内楼层”或建筑卡的入口，查看19栋建筑的78个公开楼层。支持楼层选择、整栋叠看、整栋房号检索并跳到对应楼层、点击聚焦、平面/三维视角。关闭返回保留楼层、房间与视角；照片在当前界面对照，全景提供本楼/本层入口。
- 真实房间平面共9,951个源要素、9,955个多边形部分；63层含官方CAD参考线（座椅、门扇、家具、符号等）。层间距保留源Z。升起的房间边界为0–3m可调**读图示意**，不是测量墙高、墙厚或门洞。
- 41张重点室内照片、图书馆6张实际楼层图及Shaw3张楼层图可对照。图纸叠层GLB也一并保留。
- 14处本地全景：8张地理对齐的新版1/F影像、6套旧官方VR立方体全景。7个新版走廊拍摄点之间有6条真实相邻连接；另1处独立场景。
- 联网模式按建筑与楼层选择2,044个官方公共全景节点，并沿2,116条源边移动。已实测Shaw G/F与商学楼G/F跨建筑联网加载。目录有135个连通分量、59个孤立点，不保证任意位置连续漫游。新增位置图、上一全景、键盘环顾/缩放/相邻点入口；画面朝向未独立标定成测量北向。

1m网格相对原DTM的显示重采样误差已有独立比较：247,614个共同参考点的RMSE从5m网格的0.300m降至1m网格的0.070m。它衡量同一份2019–2020资料的插值差异，不表示2026现状、测绘精度或每个位置误差都小于0.070m。仍保留源缺值和海岸边界。

定位增加来自4个命名空间的公开几何及1个明确POI；原先依赖校园图配准的粗点并未因此全部升级，约30–50m的图面配准不确定性仍需逐项参照证据。

2026-08官方校园图与2026-09-05读取的新版Path Advisor并存。新版主楼菜单含LG2/LG6等15层；旧版13层菜单不是本项目的楼层真值。CYT新版8层；部分宿舍只公开1–3层，不能推成完整宿舍内部。

`hidden_from_map`在官方代码里改变填色，而非删除几何。本项目保留全部公开底图与CAD，背景轮廓用官方浅色，无名称、不互动；具名内容保守展示。CAD包含家具和符号，不能把每一根线都拉伸成墙。官方渲染语义证据保存在 `docs/rendering-semantics-evidence.*`。

i-Village已于2026-06-11开幕，创新楼官方状态Completed；NRB2、医教研究楼及AI超级计算中心的施工/启用边界按资料单列。当前外观网格和更新包络不能替代最新竣工BIM。所有宿舍与内部区域的实际通行以校方规定和现场情况为准。

Three.js的统一局部原点为HK1980 Grid **E844800 / N820500**：`x=E−844800`、`z=820500−N`、`y=源高度`。地形y为HKPD；摄影网格和Path Advisor的绝对垂直基准没有完全核实。不得盲目加统一2.37m偏移：网格沿岸样本与DTM的实测比对表明其数值高度可能已经接近HKPD。

GLB原始摄影分块必须同时使用manifest中的列主序矩阵：

```js
const gltf = await new GLTFLoader().loadAsync('/models/' + tile.url);
gltf.scene.applyMatrix4(new THREE.Matrix4().fromArray(tile.matrix));
scene.add(gltf.scene);
```

不额外旋转Z-up或再次减原点。原始3D Tiles、地形GLB、更新GLB各自的坐标约定见本目录说明。

开发：`npm run dev`；类型检查：`npm run check`；资料完整性校验：`python3 scripts/validate-data.py`；构建：`npm run build`。构建产物在`dist/client`。本地运行需要Python3，开发构建需要Node22.13+；依赖锁文件已保留。

主网站只从本地读取资料。联网全景代理仅允许目录中已证实的公开资产ID，目标固定为`navigate.ust.hk`，没有通用URL代理、登录、上传或公开发布功能。
