# Government source checkpoint

This independently runnable copy renders the 292 retained original government GLBs. Tile revision: 2025-03-27. Its application, building/indoor index and supplemental source/evidence files were compiled in September 2026 and are labeled as annotations. Later exterior corrections and current-form replacements are disabled. This is not an exact historical 2025 application snapshot.

Run `npm ci`, `npm run check`, `npm run build`, then `python3 scripts/serve.py --port 4330`. All model and entity files are owned by this directory; nothing links to another version. Publish only the catalog.latest version from the repository root.

See VERSION.json and docs/DATA.md for dates, source boundaries and missing historical raw inputs. Whole-campus current-building acceptance does not apply to this source-era view.
