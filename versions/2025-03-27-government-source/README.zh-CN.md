# HKUST 清水湾统一校园沙盘

本机入口：[http://127.0.0.1:4317/](http://127.0.0.1:4317/)。这是清水湾校区的本地交互浏览工具，资料核对至2026-09-06；不发布到外网。双击 `启动校园地图.command`，或运行 `python3 scripts/serve.py --port 4317`。模型与公开平面从本地读取，额外官方全景按需联网。

## 浏览方式

左键拖动旋转，右键按住已拾取的地表点平移；也可开启左键平移模式。滚轮与右上按钮缩放，房屋图标回到校园全景。相机每帧检查实际地形与安全净空；没有地形证据时保留可信下限。打开的实际楼层区域可以查看低于室外地形的 LG 层。

搜索建筑、房号、电梯、设施、运动场或道路。搜索、实体树和场景点击使用相同实体ID。选择建筑后按“原位打开楼层”，楼层、房间和电梯都在校园原世界坐标中打开，周围校园继续存在。电梯只列公开资料出现的停靠层；定位会避开从楼外高地背面望向地下层的取景。房间边界升高只是读图示意，CAD座椅和门线保持源坐标。

左上角在三种语言中均使用校徽与单一HKUST标识。实体侧栏实际占据布局宽度，地图的聚焦、平移、拾取与名称标签使用剩余画布范围。外扩箭头进入沉浸地图，不调用浏览器fullscreen API，只保留“恢复界面”按钮；Escape或该按钮恢复原界面与名称设置。拖动、缩放、悬停和空白点击不退出，真正选中实体会在同一事务恢复界面并执行原选择。切换布局保留相机、目标、楼层、语言与画质。

“相关资料”替代实体卡，照片关闭后回到该资料面板，再一步返回原实体。资料按实际实体、所属建筑及有依据的楼层绑定，切换户外实体不继承旧楼层影像；附近环境与所示实体分别标明。副行保留“类型 · 建筑 · 楼层”，长聚合来源关系与其余别名保留在详情，搜索别名继续有效。“收起楼层”恢复打开前的校园视角。全景附近关系不代表房间内景。

## 精度和显示约定

统一坐标为 `x=E−844800, z=820500−N, y=sourceZ`。DTM高程为源HKPD，采集2019–2020；室内源Z的绝对基准未独立核实。1m是显示采样间距，不是新的测绘精度；楼层原多Z不压平。

逐栋模型修订2026-04-24并不证明2026拍摄或竣工。完整外观按当前视野可同时显示多栋。高清档640MiB预算只计基础RGBA纹理及投影mask，包含可见、缓存、在途预留，不含mipmap、网格或浏览器/GPU总占用。主楼基础纹理约478.72MiB。原纹理缓存随档位为48/96/192/384MiB，高清档192MiB；按逐级缩至1×1的完整RGBA mip链精确计数；两者不是同一口径。楼层缓存最多5层/32MiB估算。来源可用、当前可见、缓存与预算延后分开记录，详见[来源覆盖](docs/SOURCE-COVERAGE-v4.md)。

海面背景取原摄影远海纹理的代表色，并在有岸线/低海面证据的外边缘淡出。它修复显示色差，不生成海岸、水下地形或新实拍资料；原像素和几何文件保持不变。源资料缺失的墙高、门侧、开放权限和通路保持未知。创科大楼最高源层166.95之上加5m封顶是显示参数，屋顶并未实测；立面色带为照片参考近似，没有虚构桥或生成实景贴图。其他缺乏当前外观的实体保留来源边界，不能视为全校现状BIM。

主楼完整范围mask的红通道保留9个逐栋本体加28个源补片，绿通道只保留9个本体的真实三角投影。基线按完整范围替换；细摄影只避让独立本体，已就绪细节覆盖内才隐藏旧补片。高清纹理由摄影流复用，不再复制进完整主楼包。源图集大小不能弥补L16的粗几何和原始模糊；未取到更细源的屋顶与立面保持这一限制。

## 画质配置

可选自动、流畅、均衡、高清、最高。设置控制显示和资源预算，不改变来源精度；完整建筑/区域仍整组提交。6C-2/6/11/16与6C-1/7均已有error=0末叶fine；high中间LOD与fine整组互斥。UG10的37叶high本身已是terminal，最高档复用该级。6C-1/7及UG10只代表实际可得部分，不扩大到完整父瓦片。

|档位|DPR上限|完整外观 MiB|原纹理 MiB（含mips）|摄影细网格 MiB（含mips）|1m地形片上限|
|---|---:|---:|---:|---:|---:|
|流畅 smooth|1|160|48|0|2|
|均衡 balanced|1.25|512|96|192|4|
|高清 high|1.6|640|192|1024|6|
|最高 ultra|2|800|384|1792|8|

DPR同时受设备实际devicePixelRatio上限限制。自动auto先按CPU核心数与maxTextureSize选择流畅、均衡或高清：最大纹理小于8192或已知核心数不超过4选流畅，至少8核选高清，其余选均衡。运行时在底图完整载入、纹理/几何计数至少1.5秒未变后，采样当前帧场景更新至render返回的CPU耗时；至少180个观测帧和15秒冷却后，超过24ms的比例大于30%则逐档降低。连续5个窗口的慢帧比例均低于3%，且距上次变化至少45秒，才逐档恢复，最高不超过本次硬件初选档位。它不是单独的GPU渲染计时、显存测量或真实FPS基准。
